# 08 — Stretch: pick one

## Option A — Conway's Game of Life
- [ ] A 30×30 grid. Click cells to toggle them alive or dead.
- [ ] Play / Pause / Step / Clear / Random.
- [ ] Rules: a live cell with 2–3 neighbors survives; a dead cell with exactly 3 neighbors becomes alive.
- [ ] Important: compute the next generation into a **new** grid (don't mutate while reading).

## Option B — N-Queens visualizer
- [ ] An N×N board (N = 4–10). Place N queens so none attack each other.
- [ ] Solve with **backtracking**, animating each placement and removal.
- [ ] Show the number of steps and solutions found.

## Concepts
Simulation loops, immutability, backtracking (the same "try → recurse → undo" shape as many puzzles).
