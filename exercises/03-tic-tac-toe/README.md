# 03 — Tic-tac-toe (45 min)

## Spec
- [ ] 3×3 board rendered with CSS Grid from a `board` array (9 cells or 3×3).
- [ ] Players alternate X / O. Show whose turn it is.
- [ ] Can't play on an occupied cell.
- [ ] Detect a winner (rows, columns, diagonals) and a draw. Highlight the winning line.
- [ ] Reset button. Bonus: a scoreboard.
- [ ] Bonus: N×N board with K-in-a-row (generalize your win check!).
- [ ] Bonus: a simple computer opponent (random move → then "win if possible, else block").

## Concepts
Grid layout, `dataset.index`, data-driven win checks (an array of winning lines vs. loops).
